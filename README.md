# HelioScan

Aplicación para la evaluación técnica y financiera de viabilidad solar en techos residenciales y comerciales en México.

## Características

- **Datos de Radiación Solar:** Consulta automática de la API NASA POWER para obtener promedios mensuales de radiación solar en coordenadas específicas.
- **Motor Financiero WebAssembly:** Cálculo de retorno de inversión (ROI), amortización y ahorro estimado en la tarifa eléctrica de CFE compilado a WebAssembly (WASM).
- **Estimación de Capacidad:** Cálculo del número de módulos fotovoltaicos requeridos según el consumo en kWh.
